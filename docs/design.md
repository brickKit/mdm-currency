# mdm/currency 的设计

本页写这个组件为什么这样设计：术语、拥有的数据、规则、命令与事件、实现状态。写给要修改它的人与 AI。怎样使用、部署与配置在 `BRICKKIT.md`；代码在哪、怎样构建与测试、设计取舍在 `AGENTS.md`；跨组件的规则在装配项目的协议 02（来源要提供什么）与协议 14（标准代码、金额与舍入、列表）。

## 边界

币种与汇率的参照表：币种定义、汇率类型、每日汇率。所有使用金额的客户都需要（单币种客户也要币种定义）。

| 不在这里 | 归谁 |
| --- | --- |
| 金额的舍入与分摊 | SDK 的 `money`：本组件只提供币种的最小单位与舍入方式 |
| 反向与交叉汇率的取法 | 调用方，或以后的汇率来源适配器 |
| 外币重估、汇兑损益 | `erp/finance`（协议 05） |

## 术语

| 业务叫法 | 定义 | 代码标识符 |
| --- | --- | --- |
| 币种 | ISO 4217 的代码、数字代码、最小单位、舍入方式、现金舍入单位、启用与否、名称与译名 | `currency`（主键 `code`） |
| 汇率类型 | 汇率的用途分类；随组件只带 `spot`，其余由客户维护 | `rate_type` |
| 汇率 | 一个类型、一个日期、一个币种对（按录入的方向）的一个值，带来源 | `exchange_rate`（`rate`：`numeric(19,10)`） |
| 有效汇率 | 按类型与币种对，取不晚于请求日期的最近一条，回答带汇率日期 | `effective`、`RateService/EffectiveRate` |
| 汇率快照 | 单据保存的汇率、日期、类型、记录身份与版本；之后的更正不影响单据 | 引用方的字段 |

## 拥有的数据

| 表 | 内容 | 终态与保留 |
| --- | --- | --- |
| `currency` | ISO 4217 全表，迁移写入（`scripts/iso4217.py` 生成）；部署只改启用、舍入方式、现金舍入单位与译名 | 停用，不删除 |
| `rate_type` | 汇率类型 | 停用，不删除 |
| `exchange_rate` | 每日汇率；唯一键（类型、源币种、目标币种、日期） | 更正是同一行的新版本；不删除 |

每条记录带版本，每次变化在同一个事务里以完整状态事件发布。迁移写入的币种没有搜索列，由单例任务 `mdm.currency.search_backfill` 每 10 分钟补写。

## 规则

- 同一类型、同一日期、同一币种对只有一个有效汇率；更正是同一条记录的新版本（原地更新、版本加一），并重新发布。旧的值不留在表里，只在当时发出的事件与引用方的快照里；审计记录只写更正后的值。
- 相同内容再写一次不产生新版本，也不发事件。
- 币种对只按录入的方向，不推导反向与交叉汇率。
- 代码、数字代码、最小单位与默认名称来自标准，不开放修改：最小单位一旦被单据用过就不能改。
- 汇率的文本没有末尾零；比较是否相同按数值。

## 命令与查询

| 命令或查询 | 用户面或系统面 | 权限键 |
| --- | --- | --- |
| 修改币种（启用、舍入、现金舍入单位、译名）；维护汇率类型 | 用户面 | `mdm.currency.manage` |
| 读取与列出币种、汇率类型 | 用户面 | `mdm.currency.read` |
| 录入与更正汇率 | 用户面 | `mdm.exchange_rate.maintain` |
| 读取与列出汇率；有效汇率 | 用户面 | `mdm.exchange_rate.read` |
| 来源方法 `Snapshot`、`Read`；有效汇率 `RateService/EffectiveRate` | 系统面 | `mdm.currency.system.read` |

## 事件

流 `mdm.currency`（4 个分区），完整状态：`mdm.currency.changed.v1`、`mdm.rate_type.changed.v1`、`mdm.exchange_rate.published.v1`。业务组件取汇率用有效汇率的同步查询并在单据上存快照；事件给要在本地显示或报表的投影用。

## 依赖

不调用任何组件。身份、授权（必需）；`infra/audit`（可选：缺时审计记录留在本地，协议 03）。

## 数据范围

没有维度：币种与汇率对全部法人相同。

## 部署与替换

极低负载，适合外壳。同契约的实现可以接替；汇率来源可以替换。适用协议 02、14、16（期初汇率与币种）。

## 验证故事

| 故事 | 本版 |
| --- | --- |
| 外币订单快照汇率后汇率被更正，订单金额不变 | 本组件一侧：更正是新版本，旧版本仍可按身份与版本解释；快照由销售保存 |
| 三位小数的币种按它的最小单位舍入 | 最小单位随币种提供；舍入在 SDK |

## 未决问题

- 汇率的历史：更正之后旧值只在事件与快照里。事务与消息要求属主提供声明所需的事实历史；要不要在本组件里保留每个版本的值（以及审计写入前值），随第一个需要按版本回查的引用方（销售、财务的外币重估）定。
