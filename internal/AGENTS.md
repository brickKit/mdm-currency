# internal/：业务模块

币种与汇率的业务，每个模块一个包。只给本仓库引用（Go 的 `internal`）：别的组件编译期就引用不了，跨组件只走契约（决定 0101）。先按下表找到模块，再读那个目录的 `AGENTS.md`。

## 模块

| 包 | 一句话 | 依赖（本组件内） |
| --- | --- | --- |
| `currencies` | 币种：读取、部署能改的几项、列表与关键字、搜索列的回填 | `core` |
| `rates` | 汇率类型与汇率：录入与更正、有效汇率、列表 | `core` |
| `source` | 系统面：来源方法与有效汇率 | `core`、`rates` |
| `core`（共用） | 名字与资源定义、校验、审计与事件、记录、列表的共用部分、`Base` | — |

分层（每个包只引用比它低的层）：`source` → `currencies`、`rates` → `core`。

## 共同的写法

- 每个模块的函数先收 `m *core.Base`（运行时；来源方法盖戳用的部署与实现实例），入口包的 `Module` 持有它、登记时适配。
- 名字（资源、操作、事件类型）在 `core/names.go`；写入、审计（`core.Change`）与发件表（`core.Emit`）同一个事务。
- 相同内容再写一次不产生新版本、不发事件：每个写入先比较（`sameCurrency`、`core.SameNames`、汇率按数值）。
